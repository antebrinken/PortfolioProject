# New Project Starter

Minimal Vite + React + TypeScript + Tailwind setup.

## Commands
- Dev: `npm run dev`
- Build: `npm run build`
- Preview build: `npm run preview`

## Where to start
- Edit `src/App.tsx` and build your UI with Tailwind classes.
- Global styles (Tailwind): `src/index.css`.

## Tailwind
- Config: `tailwind.config.js`
- PostCSS: `postcss.config.js`
